# Courtroom of Love

Create a cute, playful, and responsive interactive apology web page for my girlfriend who is upset with me for not giving her enough time.

The theme should be a witty courtroom verdict style:
- Crime: Busy rehna aur tumhe time na dena
- Criminal: Main (Boyfriend)
- Judge & Victim: Tum (Girlfriend)
- Saza: Aaj shaam sirf tumhare saath waqt bitana aur tumhari saari baatein dhyaan se sunna
- Appeal: Gussa thoda kam karke ek smile bhejogi, madam?

Make it visually charming with soft pastel romantic tones, subtle floating hearts, and playful interactive elements:
1. A mock courtroom 'Verdict Notice' / 'Arrest Warrant of Love' card with the witty breakdown.
2. An interactive 'Faisla / Verdict' section:
   - "Maan Gayi / Forgive Him" button: triggers festive confetti, cute celebration animations, and a sweet romantic message with a call-to-action to call him.
   - "Abhi Bhi Gussa Hoon / Still Angry" button: a playful dodging button (runs away or shrinks playfully with funny counter-arguments like "Nahi maan sakti? Check again! 🥺").
3. A cute promise voucher for dedicating the entire evening to her.
4. Mobile-friendly, smooth animations, and warm Hindi/Hinglish copy.
